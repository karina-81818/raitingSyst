Это программа, которая запрашивает у пользователя оценку в диапазоне от 0 до 100 включительно и выводит соответствующую буквенную оценку (A, B, C, D, F).
Для запуска программы набери в терминале команду go run main go
Для получения результата нужно ввести число от 0 до 100, если будет некорректный ввод программа покажет ошибку.
