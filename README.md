
# 📊 Система оценки знаний (Rating System)

Простая консольная программа для конвертации числовой оценки (от 0 до 100) в буквенный формат (A, B, C, D, F).

## 📋 Описание

Программа запрашивает у пользователя оценку в диапазоне от 0 до 100 и выводит соответствующую буквенную оценку по шкале:

| Буква | Диапазон |
|-------|----------|
| A | 90–100 |
| B | 80–89 |
| C | 70–79 |
| D | 60–69 |
| F | 0–59 |

## 🚀 Возможности

- ✅ Проверка корректности ввода (число от 0 до 100)
- ✅ Обработка ошибок при неверном вводе
- ✅ Простой и понятный интерфейс
- ✅ Только стандартная библиотека

## 🛠 Требования

- Go версии 1.16 или выше
- Без внешних зависимостей
